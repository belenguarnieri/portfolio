# Portfolio · Belén Guarnieri

Sitio estático publicado con GitHub Pages en https://belenguarnieri.github.io/portfolio/

- `index.html`: la página completa
- `assets/videos/`: videos de los proyectos
- `assets/img/`: portadas de los videos e imagen para compartir en redes (`og.jpg`)

Para editar un texto, abrí `index.html`, cambiá el texto y guardá los cambios: GitHub Pages actualiza el sitio en un par de minutos.
